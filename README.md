To see the lab guide from Matlab (2015a):
>> mylab

To get to the webpage of the course:
>> mylab webpage

To open the Windows Explorer and show your current working folder:
>> mylab explore

In case you want a fresh copy of a Simulink DEMO files
(the files will be copied into the current folder):
>> mylab sdemo; !start view_io_readme.txt

To open the current folder in file explorer
>> !start .
